# 📌 Project Overview

The objective of this project was to build an interactive **Sales & Profitability Analytics Dashboard** using Microsoft Power BI.

The dashboard provides a consolidated view of business performance and allows users to analyze sales, profitability, products, customer segments, monthly trends, and geographic performance.

The project focuses on converting raw e-commerce data into meaningful business insights that can support data-driven decision-making.

---

# 🎯 Business Objectives

The dashboard was developed to answer key business questions such as:

* What are the total sales and total profit?
* What is the overall profit margin?
* How are sales and profit distributed across categories?
* Which customer segments have better margins?
* Which products are generating losses?
* How does sales performance change month-to-month?
* Which states generate higher sales?
* What is the current on-time delivery performance?
* Which products require further profitability analysis?

# 🚀 How to Use This Project

## Step 1 — Download the Files

Download the Power BI project and Excel dataset from this repository.

**[Download Power BI Project](project%20%282%29.pbix)**

**[Download Excel Dataset](e-commerce-company-1711263192.xlsx)**

## Step 2 — Open Power BI

Open:

```text
project (2).pbix
```

using **Microsoft Power BI Desktop**.

## Step 3 — Check the Data Source

If Power BI asks for the location of the Excel file:

1. Select **Transform Data** or **Edit Credentials** if required.
2. Update the Excel file path.
3. Select the uploaded `e-commerce-company-1711263192.xlsx` file.
4. Apply the changes.

## Step 4 — Refresh the Dashboard

Click:

**Refresh**

to load the data.

## Step 5 — Explore the Dashboard

Use the available:

* Filters
* Slicers
* KPI cards
* Charts
* Tables
* Geographic visualizations

to explore the analysis.
